## Sprint 3 — решения и вопросы

- 🟢 **Google People API через httpx напрямую** (REST), без `google-api-python-client` — меньше зависимостей, единый стиль с Microsoft. Если предпочитаешь официальную либу — переделаю.
- 🟢 **Разрешение конфликтов = last-write-wins** через `merge_contacts`: внешний источник дополняет существующий контакт (пустые поля заполняются, непустые у существующего сохраняются, телефоны/email объединяются). ❓ Устраивает, или хочешь UI выбора «какое значение оставить» при конфликте?
- 🟢 **Scheduler рассчитан на один процесс** (uvicorn без `--workers >1`). Для single-user это норм. ❓ Если будешь масштабировать на несколько воркеров — нужен внешний lock (Redis/Mongo), скажи — добавлю.
- 🟢 **Удаление контактов при удалении в источнике пока НЕ реализовано** (Outlook `@removed`, Google `metadata.deleted`) — помечаю `skipped`, чтобы случайно не потерять данные. ❓ Хочешь, чтобы удаление в Outlook/Google удаляло контакт и в CRM?
- 🟢 **Push и подписка на вебхуки — пока только через API** (UI-кнопок нет). На странице `/sync` есть подключение и ручная синхронизация. ❓ Нужна ли кнопка «Отправить контакт в Outlook/Google» в карточке и тумблер вебхуков?

## Карточка контакта (фото 1 → новая)

Шапка как в Dex: аватар, имя (Cormorant), должность, пилюли «Приоритет», «Частота», иконки соцсетей,
строка ADDED / FIRST MET / LAST INTERACTION / FREQUENCY. **Правой колонки нет.** Всё, что было в ней, —
в подвкладке «Данные». Вкладки: **Timeline · Данные · Вопросы · Досье · Календарь · Файлы** (LinkedIn убран).

- Timeline — взаимодействия этого человека + «Добавить заметку».
- Данные — связанные контакты, группы, теги (+ ИИ-автотеги), контактная информация, поля шаблона, свои поля, соцсети, источники.
- Вопросы — существующий `QuestionsPanel`.
- Досье — краткая сводка ИИ по всем полям и истории (задача `dossier` в очереди, кэш + «Обновить»).
- Календарь — встречи с человеком (`ContactEvents`).
- Файлы — `AttachmentsPanel`.

## Цели и стратегии

Пользователь выбирает подход (можно один основной и несколько дополнительных). Подход задаёт правила для контактов:
целевая частота по сегментам, сколько новых знакомств в месяц, на чём делать акцент. Встроенные подходы:

- **Максимум контактов** (широкая сеть, слабые связи по Грановеттеру): много людей, редкие касания (90–180 дн.), цель по новым знакомствам.
- **Глубокие отношения** (число Данбара 5/15/50/150): круги близости, частые касания внутреннего круга (7/30/90/365 дн.).
- **Колесо жизненного баланса**: сферы (семья, друзья, работа, здоровье, развитие, хобби…) — контакты привязаны к сферам, цель — равномерность.
- **Свой**: правила вручную.

Страница показывает выполнение (диаграммы), а Keep in Touch и Главная берут приоритеты из активной стратегии.

## ИИ-помощник 2.0

- Полноценные чаты: список слева, история сообщений, контекст разговора (последние сообщения + сводка старых) уходит в модель.
- Новые инструменты (те же функции пойдут в MCP-сервер Sprint 9): агрегаты по контактам и взаимодействиям,
  выдача **графиков** (гистограмма, линия, круговая) и **таблиц** как структурированных блоков, которые фронт рисует (recharts).
- Анализ: текстовый вывод модели рядом с графиком.

## Волны работ (агенты Sonnet, каждый в своём worktree)

**Волна 0 — фундамент (параллельно):**
- W0-A Дизайн-система и оболочка: токены, шрифты, базовые компоненты, переключатель акцента, новый сайдбар с заглушками новых разделов.
- W0-B Данные: новые поля контакта, группы, взаимодействия (timeline), keep-in-touch, API и типы фронта.
- W1-6 ИИ 2.0: чаты + история + графики (не зависит от Dex-экранов).

**Волна 1 — экраны (после слияния W0 и снятия экранов Dex):**
- W1-1 Главная + Контакты с подвкладками
- W1-2 Карточка контакта
- W1-3 Keep in Touch + Timeline
- W1-4 Карта + Сеть + Priority Map
- W1-5 Цели и стратегии

**Правила для всех агентов:** API-клиент новой фичи — в отдельном файле `frontend/lib/api-<фича>.ts`
(общий `lib/api.ts` правит только W0-B); роутер — свой файл в `backend/app/routers/`; только токены Tailwind
(никаких хардкод-цветов); тексты интерфейса на русском; тесты backend на новую логику (`pytest`); `npm run build`
и `npm run lint` зелёные; conventional commits.

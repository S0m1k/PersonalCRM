# Экраны Dex — разбор структуры (снято 2026-11-04)

Справочник для агентов волны 1. Берём **структуру и поведение**, тексты — по-русски, стиль — наши токены
([dex_tokens.md](dex_tokens.md)). Скриншоты не копируем, ассеты/иллюстрации Dex не используем.

## Оболочка

- Сайдбар (neutral-100): логотип; Home (подпункт Reminders) · Contacts (подпункты Birthdays, Quick Action,
  Merge and Fix, Locations) · Keep In Touch · Timeline · Map · Network (подпункт Insights) · Priority Map · Copilot.
  Ниже свёртываемые секции: **Favorites** (закреплённые контакты/группы/виды), **Views** (сохранённые виды списка
  контактов), **Groups** (раскрывается в список групп). Внизу: Import, Help.
- Подпункты показываются, когда активен родительский раздел.
- Верхняя панель: поиск на всю ширину («Поиск (/)…»), справа — синхронизация, «+» (быстро добавить), переключатель правой панели.
- Правая выезжающая панель на Главной — «С чего начать» (чек-лист онбординга) и промо-карточка «Карта».
- Заголовки страниц — Cormorant ~32px, под ними строка-подзаголовок 12–13px muted. Главная кнопка страницы — справа сверху, primary с «+».

## Главная `/`

1. Приветствие по времени суток: «Добрый вечер, {имя}» (Cormorant) + справа иконка мессенджера.
2. Большое поле-ввод ИИ (rounded-2xl, лёгкая тень, accent-обводка) с плейсхолдером-примером
   «С кем я не общался 3 месяца?», кнопки голос/отправить. Отправка → открывает чат помощника с этим вопросом.
3. Секции списком (заголовок 13px medium + пустое состояние muted): **Календарь** (события сегодня),
   **Дни рождения** (+ «Все дни рождения»), **Keep in touch** (кому пора написать), **Напоминания** (+ «Все напоминания»),
   **Обновления сети** (недавние изменения: новые взаимодействия, смены компаний и т.п.).
- `/reminders` — список напоминаний (дата, контакт, текст, отметка «сделано»), пустое состояние + «Добавить напоминание».
  У нас аналога сущности нет → напоминания = вопросы/задачи с датой; если проще, отдельная коллекция `reminders`.

## Контакты `/contacts`

- Заголовок «Все контакты», «N контактов», кнопка «Добавить контакт».
- Строка инструментов: выбор вида (дропдаун «Все контакты» + «+» создать вид), справа фильтр, сортировка, видимость колонок, поиск.
- **Таблица**: чекбокс, Имя (аватар+имя), Должность (inline «Добавить…»), Частота («Задать частоту»), Соцсети (иконки),
  Последнее взаимодействие («Никогда»/дата), «+» добавить колонку. Множественный выбор → массовые действия (теги, группа, частота, удалить).
- Сохранённые виды (Views) = имя + фильтры + колонки + сортировка; показываются в сайдбаре.
- Подразделы:
  - **Дни рождения** `/contacts/birthdays` — ближайшие по месяцам, поиск; пустое состояние.
  - **Быстрые действия** `/contacts/quick-action` — «игра»: стопка карточек (аватар, имя, должность, описание, последнее
    взаимодействие), клавишами выставляешь приоритет (1–5) и частоту; кнопка «Начать (Enter)», счётчик
    «N без приоритета · N без частоты».
  - **Слияние дублей** `/contacts/merge` — предложения дублей (у нас есть `sync/dedup.py`), «Объединить»/«Не дубль», кнопка обновить.
  - **Места** `/contacts/locations` — две колонки: слева список контактов (фильтр, поиск, drag-handle), справа места;
    перетаскивание контакта на место, «Добавить место».

## Keep in Touch `/keep-in-touch`

- Заголовок + подзаголовок, переключатель вида **Доска · Список · Ближайшие**, фильтр по группе/виду, «Настройки отображения».
- **Доска**: колонки по частоте — Без частоты · Каждую неделю · Раз в 2 недели · Раз в месяц · Раз в квартал · Раз в полгода · Раз в год;
  карточки контактов перетаскиваются между колонками (= смена частоты); в карточке — просрочка.
- **Список**: таблица с due date / просрочкой, действия «Связался», «Отложить».
- **Ближайшие**: группировка Просрочено / На этой неделе / Позже.

## Timeline `/timeline`

- Заголовок, подзаголовок «Встретились с кем-то? Запишите…», кнопка «Добавить заметку».
- Справа над лентой: настройки, фильтр (тип, контакт, период), поиск.
- Лента сгруппирована по месяцам («НОЯБРЬ 2026»), строка = иконка типа + заголовок + контакты + дата справа.
- Пустое состояние с иконкой часов.

## Карта `/map`

- Карта на ~70% ширины (rounded-2xl), поиск места поверх карты, зум +/−; справа панель «N контактов в области»
  (сортировка/фильтр), внизу справа карточка «Контакты по местам» → ведёт в `/contacts/locations`.
- Список справа синхронизирован с областью карты. Пины кластеризуются.
- Dex использует Mapbox. Нам: **MapLibre GL + бесплатные тайлы OpenStreetMap** (или Leaflet + OSM), без ключей.

## Сеть `/network`

Сегмент-переключатель сверху: **Вселенная · Группы · Связи · Компании**; подпункт **Инсайты**.
- **Вселенная** — тёмный фон со звёздами; каждый контакт — звезда, позиция по сходству профиля
  (должность, компания, заметки), кластеры с названиями. Нужно ≥ 8 контактов с профилем. У нас: кластеризация
  по TF-IDF/эмбеддингам (локально), подписи кластеров — ИИ; можно упрощённо: группировка по компании/тегам/городу + force-layout.
- **Группы** — радиальный граф: «Я» в центре, группы вокруг, контакты у своих групп; панель справа «Добавить группу», поиск,
  «Как пользоваться»; внизу лоток «Без группы N» + «Разложить с ИИ».
- **Связи** — граф связанных контактов (relationships + совместные встречи); перетащить контакт на другой = связать.
- **Компании** — «Я» в центре, компании вокруг, люди у компаний; «Показать без компании N».
- **Инсайты** `/network/insights` — «Кто ваша сеть одним взглядом»: распределения по компаниям, городам, отраслям,
  частоте общения, давности взаимодействий (графики), нужно ≥ 20 контактов.

## Priority Map `/priority-map`

- Полукруглые концентрические дуги вокруг аватара «Я» сверху по центру; уровни от центра:
  **Топ · Высокий · Средний · Низкий · Нет**; на каждой дуге — подпись уровня и счётчик, контакты — аватары на дуге.
- Справа плавающая панель: «N% с приоритетом · N из M», поиск, фильтр по группе, «Уровни» с полосками-заполненности
  (+ «Не задан»), «Как пользоваться», шестерёнка — переименовать уровни.
- Внизу лоток «БЕЗ ПРИОРИТЕТА N» с аватарами, «Расставить приоритеты» (→ Быстрые действия), «Скрыть».
- Перетаскивание аватара на дугу = смена приоритета. Кнопка «Сбросить вид» (зум/панорама).
- Данные: `priority` расширяем до `top|high|medium|low|none` (+ пусто = не задан); названия уровней — настройка пользователя.

## Copilot → наш «Помощник» `/assistant`

Пустой чат: заголовок по центру, подзаголовок, большое поле ввода, чипы-подсказки. Справа узкая панель: «Новый чат», список чатов.
Сноска «Ответы могут быть неточными — проверяйте».

## Карточка контакта (см. фото пользователя)

Шапка: аватар 80px, имя Cormorant, «Добавить должность…», пилюли «Приоритет» и «Частота», иконки email/LinkedIn/Facebook/Instagram,
справа «поделиться», «ИИ», «⋯». Блоки «ОПИСАНИЕ», «ИЗ СЕТИ» (у нас — «Досье ИИ»), строка ДОБАВЛЕН / ПЕРВАЯ ВСТРЕЧА /
ПОСЛЕДНЕЕ ВЗАИМОДЕЙСТВИЕ / ЧАСТОТА. Ниже вкладки. В Dex справа колонка карточек (Связанные, Группы, Теги с ИИ-автотегом,
Контактная информация, Свои поля, Соцсети) — **у нас эта колонка становится вкладкой «Данные»**.
